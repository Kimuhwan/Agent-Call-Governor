# Agent Call Governor v0.3.0

Agent Call Governor v0.3.0 is a local-first observe/warn plugin for Codex. It records sanitized lifecycle and deterministic policy facts in local SQLite while preserving quality floors for necessary calls. It is not a firewall: the bundled Codex hook does not emit the host's supported `PreToolUse` denial response.

## Highlights

- Root Codex plugin with six lifecycle hooks for sessions, direct tools, and subagents.
- Schema-v2 SQLite ledger with transactional policy decisions, multi-process delivery handling, bounded fail-open behavior, recovery, retention, inspection, reporting, sanitized export, and secure deletion.
- Fingerprint v2 that preserves material case and list order, incorporates tool/cwd/state context, and ignores only object-key order.
- Strict, balanced, and quality-first policy profiles with separate agent/direct-tool budgets and a high-risk retry floor.
- English and Korean onboarding, operational documentation, and a companion Python runtime for application-owned enforcement and supported SDK guardrails.

## Compatibility

- Python 3.10 or newer is required; the release gate includes Python 3.14.3.
- The plugin targets the Codex plugin and hook contracts documented on 2026-07-15. Codex can deny a supported `PreToolUse` call, but this release deliberately remains observe/warn-only at the host hook boundary.
- Installing or enabling the plugin does not trust its hooks. Review the current command and exact hook hash in `/hooks`, then explicitly trust that exact version. Any hook change requires review and trust again.
- Migrated legacy-v1 rows continue to contribute to budget and progress accounting, but fingerprint v2 begins a new exact-duplicate epoch.

## Privacy

- The plugin has no required remote telemetry and keeps its authoritative ledger in local SQLite.
- Raw prompts, objectives, tool arguments, tool responses, transcripts, host session/call/turn/parent identifiers, and exception messages are excluded from persistence. Relevant identities are represented by SHA-256 references; hashing minimizes stored data but is not encryption.
- Exports are sanitized and atomic. SQLite, WAL/SHM files, and exported JSONL still contain sensitive operational metadata and should not be placed in public or shared storage.
- Hook and database failures are bounded and fail open, which preserves Codex availability but can create an observability gap.
- GitHub private vulnerability reporting is not currently enabled. Follow [SECURITY.md](../../SECURITY.md) and never place vulnerability details or secrets in a public issue.

## Measured validation

- Deterministic policy regression: **19/19** cases, with zero reported failures.
- Enforce-mode runtime replay: **64/64** workloads, preserving **96/96** necessary calls and blocking **32/32** redundant calls, with zero under-call failures.
- Instrumentation pilot: **10/10** selected contracts for exact/changed fingerprints, high-risk low-progress retries, multi-process budget contention, bounded lock handling, recovery, and SQLite reopen persistence. See the [mechanically rendered result](https://github.com/Kimuhwan/Agent-Call-Governor/blob/v0.3.0/evals/instrumentation-results-2026-07-15.md).
- The earlier four-task matched Codex A/B trial completed all tasks in both conditions and is retained only as small directional evidence.

Current deterministic, instrumentation, and small matched A/B results are directional evidence, not production benchmarks.

## Known limitations

- The installed Codex hook is observe/warn-only and process-level fail-open; it does not provide host-level blocking. Application-owned wrappers and supported SDK guardrails are separate enforcement surfaces.
- Exact fingerprints do not detect semantic or near-duplicate calls.
- Policy replay is deferred to v0.4 after schema-v2 logs exist.
- Live workload task-success, cost, latency, and under-call rates have not yet been established.
- Local hashes can reveal equality and low-entropy values may be guessable. Local account compromise, arbitrary code execution, copied databases, backups, and external side channels are outside the threat model.

## Install/update

The Codex Desktop marketplace entry follows mutable `main`; installing from that entry is not an immutable version pin. Immutability applies to the `v0.3.0` tag and release assets. Install the plugin from `Kimuhwan/Agent-Call-Governor`, or install the attached wheel for the companion runtime, and compare what you review with the tagged release before trusting it.

After installation or update, open `/hooks`, inspect the command and exact hook hash, and explicitly trust that exact hash. Run `agent-call-governor-runtime doctor --plugin-root <plugin-root> --db <path-to-events.sqlite3> --json` against the same database used by the plugin before relying on local records. Re-review and re-trust whenever hook content changes.

## Checksums

Exact SHA-256 values for the wheel, source distribution, and plugin ZIP ship in the attached `SHA256SUMS.txt`. The checksum asset never includes itself.
